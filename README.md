# NANO SWARM — ナノボット操縦ゲーム

数万体のナノボット（光の粒）を操って、空中にいろいろなものを組み上げるブラウザゲームです。PC でもスマホでも遊べます。

▶ **プレイ: https://bubbleshaker.github.io/nanobot-swarm/**

## できること
| タブ | 内容 |
| --- | --- |
| 🔤 文字 | 入力した文字に、群れがリアルタイムで組み変わる（日本語・絵文字も可） |
| 🎨 色 | 元の色／単色／グラデーション／レインボー |
| ⬢ 数 | ナノボットの数を 300〜20,000 体で変える。3D 回転、爆散 |
| 🐉 乗り物 | ドラゴン・レースカー・ロケット・UFO・ヘリを作って操縦（WASD・矢印キー・ドラッグ、Space で噴射） |
| ⚔️ 剣 | ナノブレードを作って振り、浮かんでいるブロックを斬る |
| 🐈 動物 | ネコ・ウマ・ワシ・イルカなどを作り、歩かせる・飛ばせる・泳がせる（タップした場所へ移動） |
| ✏️ お絵描き | 描いた線をナノボットがなぞる。「固める」で立体にして浮かべる |
| 🖼️ 名画 | 星月夜・モナ・リザ・神奈川沖浪裏・真珠の耳飾りの少女・叫びを、色ごと再現 |
| 🧙 召喚 | ナポレオン、ダ・ヴィンチ、織田信長、クレオパトラ、アインシュタイン、架空の人物を呼び出して会話する。「連れ出す」でドラゴンに乗せて一緒に飛べる |

## 技術
- ビルド不要の静的サイト（HTML / CSS / ES Modules、外部ライブラリなし）
- 粒子はばねと減衰で目標点へ寄せる。目標点は、オフスクリーン canvas に描いた文字・絵文字・図形・画像のピクセルから抜き出す
- 描画は ImageData への加算合成と、縮小した画像を重ねるにじみ（ブルーム）
- 会話はサーバーを使わず、人物ごとのキーワード応答で返す
- `?pv=1` を付けると、PV 撮影用の決定論モードになる
